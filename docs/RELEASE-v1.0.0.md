# LightTodo 1.0.0

轻一点，做得到。首个公开版本，采用暖白底色与马卡龙卡片配色。

## 下载

- Windows：下载 `LightTodo-1.0.0-win-x64.exe`，双击按向导安装。
- macOS：下载 `LightTodo-1.0.0-mac-universal.dmg`，打开后将应用拖入 Applications。
- 无需安装开发工具，不需要登录账号。

## 功能

- 新增、编辑、删除、搜索待办；勾选后灰化、划线并移到未完成项下方。
- 今日、本周、本月、今年筛选；今日包含之前未完成的事项。
- 可调整窗口大小、置顶和整体透明度。
- 中英文切换，默认中文。
- 自选本地数据文件夹，自动保存、备份导出及恢复。
- 长清单和设置面板支持上下滚动。

## 安装和验证说明

本版本没有受信任的开发者签名。Windows 可能出现 SmartScreen 提示；Mac 未经过 Apple 公证，使用本地 ad-hoc 签名满足运行时需要，仍可能被 Gatekeeper 拦截。确认下载来源后，按系统提示操作，无需关闭系统安全保护。

Windows 已进行本机真实 Electron 交互验证。macOS 通过托管 macOS runner 构建与自动化检查；没有 Mac 真机人工验收。每个平台的最终测试结果以本标签关联的 Actions 任务为准。
