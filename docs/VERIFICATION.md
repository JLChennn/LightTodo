### 验证边界

- macOS 托管 runner 的自动化验证不等于 Mac 真机人工安装验收；没有用户 Mac 参与验收。
- Windows 不含受信任的代码签名；macOS 采用本地 ad-hoc 签名，不含 Apple Developer ID 签名或公证。
- 未宣称 Windows ARM、旧系统、多设备同步盘并发写入、文件断电耐久性测试通过。
- 自动备份是上一次写入前的版本；重要数据仍应定期导出独立备份。
- 应用没有账号、云同步、提醒通知、重复任务、自动更新或托盘驻留功能。这些不属于本次已确认范围。
