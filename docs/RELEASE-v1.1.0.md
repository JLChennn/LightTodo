# LightTodo 1.1.0

- 极简界面：移除装饰性标题、鼓励语、欢迎卡片和进度卡片。
- 支持拖拽排序与上移 / 下移按钮，自动保存顺序；保留已完成项下移规则，兼容旧清单文件。
- 安装版新增「开机自启动」开关，默认关闭，注册当前用户登录启动项。
- 每次启动以最小窗口显示在主屏幕左上角，仍支持自由缩放和移动。
- Windows 安装向导支持自定义目录，提供中文 / 英文界面；macOS 可将 app 复制到自选目录。
- README 更新实际 UI 展示、安装路径操作和 clone 后使用 AI 自行 DIY 的说明。

下载 Windows x64 `.exe` 或 macOS Universal `.dmg`。应用数据保留在本地，升级前建议导出备份。

本版本无受信任开发者签名；Mac 为 ad-hoc 签名，未公证、未做真机人工验收。自启动验证区分启动项注册与真实重启登录；本次不重启用户电脑。详细验收记录见仓库文档。
